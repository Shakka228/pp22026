# Practice 5 – Python Regular Expressions

This project demonstrates the use of Python Regular Expressions (`re` module) and includes a program that parses receipt data from a raw text file.

## Files

* `receipt_parser.py` – Python script for extracting receipt information
* `raw.txt` – Raw receipt data
* `README.md` – Project description



The program extracts:

 Product names
 Prices
 Total amount
 Date and time
 Payment method
