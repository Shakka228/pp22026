# PhoneBook Extended

## Features
- Multiple phone numbers per contact
- Groups support
- Email and birthday fields
- Search by name/email/phone
- JSON import/export
- Pagination
- Stored procedures

## Setup
1. Create database:
   CREATE DATABASE phonebook;

2. Run:
   schema.sql
   procedures.sql

3. Install:
   pip install psycopg2

4. Run:
   python phonebook.py
